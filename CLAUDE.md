## Project Overview

React Native Pencil Kit - iOS PencilKit framework porting library for React Native using Fabric architecture.

- **iOS only**: This library is iOS-specific and requires iOS 14.0+
- **Fabric-only**: Uses React Native New Architecture (Fabric) with TurboModules and Codegen
- **Native implementation**: Objective-C++ (.mm) files for bridging React Native with iOS PencilKit framework

## Development Commands

### Linting and Type Checking
- `yarn lint` or `yarn t`: Run all linters (ESLint + clang-format + TypeScript)
- `yarn lint:js`: ESLint only for JS/TS files
- `yarn lint:ios`: clang-format check for iOS native code (requires clang-format installed)
- `yarn typecheck`: TypeScript type checking without emitting files
- `yarn format`: Format iOS native code with clang-format

### Building
- `yarn prepack`: Build the library using react-native-builder-bob (outputs to `lib/`)
- `yarn clean`: Remove build artifacts (`example/ios/build` and `lib`)

### iOS Development
- `yarn xcode`: Open example app in Xcode
- `yarn pod`: Install CocoaPods dependencies with New Architecture enabled
- `yarn codegen`: Generate Fabric component specs
- `yarn ios`: Run example app on iOS simulator
- `yarn dev`: Start Metro bundler for example app

### Release
- `yarn release`: Create a new release with conventional changelog
- `yarn release:pre`: Create a pre-release

## Architecture

### Fabric Component Structure

The library uses React Native Codegen to generate native component specs:

1. **Spec Definition** (`src/spec/RNPencilKitNativeComponent.ts`): TypeScript interface that defines native component props, events, and commands. This is processed by Codegen to generate C++ Fabric component descriptors.

2. **Native Implementation** (`ios/RNPencilKit.mm`): Objective-C++ implementation that:
   - Wraps `PKCanvasView` from iOS PencilKit framework
   - Implements `PKCanvasViewDelegate` and `PKToolPickerObserver` protocols
   - Bridges events from native to React Native using event emitters
   - Handles imperative commands via `RCTComponentViewHelpers`

3. **React Component** (`src/component/PencilKit.ios.tsx`): TypeScript wrapper that:
   - Provides typed ref with imperative methods
   - Uses `findNodeHandle` for async native module calls
   - Processes React Native `ColorValue` to native color integers
   - Falls back gracefully on unsupported iOS versions

4. **TurboModule Utilities** (`src/spec/NativeRNPencilKitUtil.ts`, `ios/RNPencilKitUtil.mm`): Async native functions for:
   - Drawing data I/O (base64, file system, PNG/JPEG export)
   - Version capability checks

### Key Implementation Details

- **Manual Framework Linking**: PencilKit.framework must be manually linked in Xcode project settings due to Objective-C++ limitations with Fabric
- **Canvas Recreation**: When loading drawings, the entire `PKCanvasView` is recreated to properly reset undo/redo stack
- **Codegen Config**: Defined in `package.json` under `codegenConfig` with `jsSrcsDir: "src/spec"`
- **Builder Bob**: Configured to output CommonJS, ES modules, and TypeScript declarations

### Directory Structure
- `src/`: TypeScript source (component, specs, utilities)
- `ios/`: Native iOS implementation (Objective-C++)
- `example/`: Example React Native app for testing
- `lib/`: Build output (generated by builder-bob)

## Important Constraints

### iOS Platform Specifics
- Only iOS 14.0+ is supported (check with `PencilKitUtil.isPencilKitAvailable()`)
- Some tools require iOS 16.4+ (e.g., `eraserFixedWidthBitmap`, width parameter for erasers)
- iOS 17+ tools: `monoline`, `fountainPen`, `watercolor`, `crayon`

### Native Development
- All iOS files use `.mm` extension (Objective-C++) due to Fabric C++ interop requirements
- Follow clang-format style (enforced by `script/clang-lint.sh`)
- Native code changes require running codegen and pod install

### Testing Limitations
- No unit tests for native code currently exist
- Manual testing via example app is primary validation method
